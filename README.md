# GitHub Pages deployment

This directory is a standalone static version of the S.H.*.T Journal Thesis Presentation.

To publish it under `https://shellyalgms-byte.github.io`:

1. In the `shellyalgms-byte` GitHub account, create a **public** repository named `shellyalgms-byte.github.io`.
2. Upload the contents of this directory to the repository root, including `index.html` and the `assets` folder.
3. In the repository, choose **Settings → Pages**, set **Source** to `Deploy from a branch`, then select the `main` branch and `/ (root)`.
4. Save and wait for GitHub Pages to finish publishing.

The site will then be available at `https://shellyalgms-byte.github.io`.
